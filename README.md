# KUDA-Frontier AI Firewall-to-Endpoint Shield

KUDA is an autonomous AI security agent that lives AFTER the firewall. Built 100% with Meta AI

### The problem
Firewalls only check the gate. Once malware is inside via email, USB, or browser you are on your own. SMEs and users in AFrica have no affordable SOC.

### The Solution
1. Email Shield - Phishing analysis
2. File Shield -AI scans files
3. Web Shield -Phishing analysis
4. Endpoint Auto-Response- Kill and quarantine
### Tech Stack
FastAPI, Python, Meta Muse SPark/ Glimmer, Baseten, WireGuard
